初次設定

此系統需要連接 Supabase 資料庫才能讓所有成員資料即時同步。
請依以下步驟完成設定（只需設定一次）。
步驟 1　建立免費資料庫

前往 supabase.com → New project → 記下 Project URL 和 anon key

步驟 2　建立資料表

在 Supabase 後台點 SQL Editor，貼上以下 SQL 執行：

點擊複製 create table attendance ( id uuid primary key default gen_random_uuid(), date_str text not null, person text not null, status text, updated_at timestamptz default now(), unique(date_str, person) ); create table course_dates ( id uuid primary key default gen_random_uuid(), date_str text unique not null, cancelled boolean default false ); create table members ( id uuid primary key default gen_random_uuid(), name text unique not null, sort_order int default 0 ); alter table attendance enable row level security; alter table course_dates enable row level security; alter table members enable row level security; create policy "allow all" on attendance for all using (true) with check (true); create policy "allow all" on course_dates for all using (true) with check (true); create policy "allow all" on members for all using (true) with check (true);
步驟 3　填入連線資訊
連線失敗，請確認 URL 和 Key 是否正確
